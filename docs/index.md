# Стабилизация взгляда в VR: результаты экспериментов

Сайт — отчёт по заданию 3 «Генераторы статических сайтов для публикации результатов исследований».
Тема сайта — материалы моего проекта по ассистивным ИТ-решениям: запись взгляда и движения головы в VR-музее и обучение модели-стабилизатора для пользователей с нарушениями моторики.

**Автор:** Кожевяткина Марина Алексеевна, группа 1.3, магистратура Университета ИТМО (разработка ассистивных ИТ-решений).

## О проекте

Цель планируемого датасета — собрать достаточный объём записей взгляда и движения головы в VR, чтобы обучить и провалидировать модель стабилизации, а также сравнить пользователей с ОВЗ (нарушения моторики, влияющие на устойчивость удержания взгляда и головы) и пользователей без ОВЗ. Это позволит мне оценить, насколько сильнее выражен тремор в первой группе и насколько эффективнее для неё работает стабилизация.

Я уже реализовала и проверила на пилотной записи (8 сессий, 17 132 строки) весь конвейер: запись одной кнопкой, автоматическая статистика и разметка без ручного труда, обучение стабилизатора и экспорт в Unity. При расширении выборки инфраструктуру менять не потребуется — нужно будет только собрать данные по протоколу.
