## Аннотация

Работа посвящена воспроизводимой публикации результатов исследования: расчёт по данным встроен в сборку статического сайта, сайт собирается и выкладывается конвейером CI без ручных действий. В качестве данных использована моя пилотная запись взгляда в VR-музее (8 сессий, 17 132 строки). Выполнены исследовательское задание T3 (обзор отечественных платформ CI/CD и хостингов), практическое задание P3 (конвейер «данные → результат → сайт»), а также оформлен и опубликован собственный GitHub Action `rsync-ssh-deploy` для выкладки по SSH.

Сайт опубликован на GitHub Pages и Cloudflare Pages, сборка и выкладка выполняются в GitHub Actions. Все измерения (время сборки и развёртывания, вес страниц) приведены в таблицах, ошибки, найденные в работе, разобраны в разделе «Отладка».
