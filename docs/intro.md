# 1. Введение

## 1.1. Цель и задачи

Цель работы — показать, как результаты исследования по записи взгляда в VR публикуются в виде статического сайта так, чтобы опубликованная страница всегда соответствовала версии данных и кода.

Задачи:

1. Выполнить исследовательское задание T3: сравнить отечественные платформы CI/CD и варианты размещения статического сайта, оценить трудозатраты на перенос workflow.
2. Выполнить практическое задание P3: встроить расчёт по данным (таблицы, графики, метка версии) в сборку сайта, показать обновление при изменении данных и работу кэша.
3. Настроить конвейер GitHub Actions (проверка, сборка, выкладка на два хостинга, проверка опубликованной страницы).
4. Оформить и опубликовать собственный GitHub Action для выкладки по SSH с семантическим версионированием, лицензией и README.
5. Снять измерения (время сборки и развёртывания, вес страниц) и разобрать ошибки, возникшие в работе.

## 1.2. Исходные данные

Данные — моя пилотная запись из VR-музея, сделанная 16 сентября 2026 года: 8 CSV-файлов, 17 132 строки, 206 секунд записи. Подробное описание формата и особенностей данных — в разделе [4. P3](practice/p3-pipeline.md).

Сырые записи взгляда относятся к персональным данным участников, поэтому они не покрываются лицензиями репозитория (см. [раздел 9](links.md)).

!!! warning "Отступление от условий"
    Условия просят опубликовать сайт на GitHub Pages и на отечественном хостинге. Отечественный хостинг в этой работе не разворачивался: второй площадкой выбран Cloudflare Pages, который к отечественным не относится. Для перехода на отечественный хостинг подготовлено всё, кроме самого сервера: сравнение вариантов в разделе T3 и action `rsync-ssh-deploy`, которому достаточно SSH-доступа и ключа. Выкладку по SSH на постоянный сервер я не проверяла: проверка проведена на локальном `sshd` внутри раннера CI.

Отчёт опубликован самим сайтом в разделе «Ход работы» и связанных разделах. Нумерация разделов совпадает с оглавлением на титульной странице. Скриншоты и таблицы относятся к конкретным коммитам и запускам, номера которых указаны рядом с ними.
